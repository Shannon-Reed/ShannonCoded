SIP Routing Flow

Developed a Go-based telecommunications routing API that simulates SIP gateway selection using configurable routing rules stored in cloud-hosted PostgreSQL.

The application processes HTTP routing requests, validates call information, dynamically selects SIP destinations based on geographic regions, and persists routing decisions for future analytics.

Designed with modular routing and database components, PostgreSQL connection pooling, parameterized SQL queries, context-based timeouts, and automated Go unit tests.
